# Limitaciones actuales

- El entorno de generación no dispone de Android SDK: no se afirma que `assembleDebug` haya corrido aquí.
- El catálogo incluido es de ingeniería/MVP, no el currículo final de miles de actividades.
- TTS del sistema depende de las voces instaladas en el teléfono.
- El mapping de taps depende del firmware del audífono; Android ve comandos multimedia, no taps físicos universales.
- POMDP actual es un lookahead de un paso, no una solución exacta de horizonte largo.
- `ParticleMasteryFilter`, `MemoryEnsemble`, MIRT y CDM están implementados como componentes disponibles pero todavía no todos participan en la política por defecto.
