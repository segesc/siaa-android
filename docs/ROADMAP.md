# Roadmap

## v0.7 - actual
Arquitectura Android multimódulo, audio/headset loop, runtime, persistencia, planificación avanzada online, content pack versionado, generación controlada y UI de operación/diagnóstico.

## v0.8 - hardware hardening
- compilar y ejecutar en Android SDK real;
- pruebas instrumentadas;
- matriz de modelos de audífonos;
- resolver diferencias OEM de media buttons/background;
- clips pregrabados para contrastes fonológicos críticos;
- recuperación explícita de sesión tras process death.

## v0.9 - content scale
- expandir catálogo a 1,000+ actividades revisadas;
- importar más KCs Pre-A1-B2 desde perfiles de referencia;
- crear batería C1/C2 manualmente validada;
- herramientas editoriales para source/provenance y QA lingüístico.

## v1.0 - release candidata
- currículo de cobertura definida Pre-A1-C1/C2;
- calibración estadística de pesos con datos longitudinales reales;
- N-of-1 y evaluación prequential;
- QA lingüístico y de accesibilidad;
- APK/AAB reproducible y firmado.
