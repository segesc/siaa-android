# Manifiesto del ZIP

- `app/`: aplicación Android y contenido demo.
- `core/model/`: tipos puros.
- `core/algorithm/`: matemática/adaptación.
- `core/runtime/`: tutor ejecutable independiente de Android.
- `core/data/`: persistencia Room.
- `core/audio/`: TTS, foco de audio, desconexión y earcons.
- `docs/`: arquitectura, build, algoritmos, medios, contenido, privacidad y roadmap.
- `scripts/`: validación, smoke tests y bootstrap Gradle.
- `tools/`: programas Kotlin de prueba.
- `reference/`: PDF maestro y checksum.
- `research_sources/`: política de procedencia sin redistribuir fuentes de terceros.
